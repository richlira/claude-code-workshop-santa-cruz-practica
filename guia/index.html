Nueve demos y dieciséis ejercicios sobre un solo repo de juguete, sur-caja: una API chica de pedidos y pagos QR con un bug plantado. El repo es disfraz; el músculo es el loop: explorar → plan → implementar → verificar → commit, y después codificarlo en skills, hooks, MCP, subagents, scripts y el Agent SDK.

Claude Code + plan pago Node ≥ 22.18 git jq (EJ 12, opcional) Ollama + modelo chico (EJ 16) API key de platform.claude.com (EJ 14-15)
Antes de empezar: al abrir claude en este repo aceptá el trust del folder y revisá sus hooks y su MCP cuando te lo pida: ese diálogo es parte de la lección. Todo lo “sensible” del repo (.env, tickets, montos) es utilería falsa. ./reset-demo.sh lo deja como al inicio.

Setup check

  1. claude --version responde y claude ya hizo login una vez.
  2. node --version da 22.18 o más nuevo.
  3. cd sur-caja && npm test → 2 verdes y 1 rojo. El rojo es a propósito (SC-101).
  4. Para EJ 14 y 15: cd agent && npm install con red, y una API key de platform.claude.com con unos dólares de crédito (el Agent SDK no usa el login de claude.ai).
  5. Para EJ 16: Ollama reciente con un modelo chico ya descargado y corrido una vez.
