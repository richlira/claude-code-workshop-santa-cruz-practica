# SC-103 · Un pedido ya cobrado acepta un segundo pago

**Reportado por:** caja, sucursal Equipetrol
**Severidad:** alta (plata duplicada)

## Qué pasa
Un cliente paga el pedido por QR y el pago queda `pagado` y el pedido `cobrado`.
Si la app reintenta `POST /pagos` con el mismo `pedidoId` (doble tap, red lenta),
el server crea OTRO pago `pendiente` para el mismo pedido y responde 200.

## Esperado
`crearPago` sobre un pedido con `estado === "cobrado"` tiene que fallar con
`Error("pedido_ya_cobrado")`. Un pedido se cobra una sola vez.

## Actual
`crearPago` solo valida que el pedido exista y que el monto coincida. No mira
el estado del pedido ni si ya hay un pago para él.

## Repro
1. `crearPedido(40)` → `crearPago(pedido.id, 40)` → `marcarPagado(pago.id, <ahora>)`
2. `crearPago(pedido.id, 40)` de nuevo
3. Esperado: lanza `pedido_ya_cobrado`. Actual: devuelve un segundo pago `pendiente`.
