# SC-102 · Falta conciliar(): saber si un pago realmente se cobró

**Reportado por:** contabilidad
**Severidad:** media (feature)

## Qué falta
Una función `conciliar(pagoId)` en `src/pagos.ts` que devuelva
`{ ok: boolean; motivo: string }`:

- `ok: true`, `motivo: "pagado"` si el pago existe y `estado === "pagado"`
- `ok: false`, `motivo: "pendiente"` si existe y sigue pendiente
- `ok: false`, `motivo: "fallido"` si existe y falló
- `ok: false`, `motivo: "inexistente"` si el id no existe

## Caso que hoy nadie cubre
Pago creado y NUNCA marcado como pagado → `conciliar()` debe dar
`{ ok: false, motivo: "pendiente" }`. Contabilidad lo necesita para el cierre.

## Restricciones
No tocar `pedidos.ts`. No cambiar el stack. Un test por caso.
